## 🚀 Getting Started (3 Steps)

### Step 1: Install
```bash
npm install
```

### Step 2: Configure Firebase
```bash
# Copy template
cp .env.example .env.local

# Add your Firebase credentials to .env.local
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
# ... etc
```

### Step 3: Run
```bash
npm run dev
```

**Done!** App runs at `http://localhost:5173`
